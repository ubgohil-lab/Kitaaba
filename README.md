# Kitaaba — local setup

1. Install Node.js 18+ (https://nodejs.org) if you don't have it.
2. Open this folder in VS Code.
3. Open a terminal in VS Code (Terminal > New Terminal) and run:

   npm install
   npm run dev

4. Open the URL it prints (usually http://localhost:5173).

Edit src/Kitaaba.jsx to change any content, copy, or styling.
